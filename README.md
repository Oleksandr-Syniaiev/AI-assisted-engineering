# AI-Assisted Engineering

Откройте **[index.html](index.html)** в браузере двойным щелчком. Это главная страница курса: пять разделов, все темы, поиск и фильтр доступных уроков. Ещё не написанные материалы отмечены **Coming soon**.

Страница работает локально без сервера и установки пакетов. Из готового урока можно вернуться по ссылке «Все разделы» в верхней панели.

## Обновление навигации

После добавления уроков выполните из корня проекта при установленном Node.js:

```shell
node build-course.mjs
```

Скрипт читает CURRICULUM.md и сохраняет автономный index.html. Порядок и названия тем берутся из curriculum; поясняющие названия разделов заданы в build-course.mjs и не меняют исходный план.

Папка урока должна иметь вид lessons/01/01-agent-basics: номер раздела и двухзначный префикс позиции в разделе. Ссылка появляется при наличии lesson.md и index.html в этой папке; одни research/outline не делают урок доступным. Статус «Доступен» означает наличие материала для чтения, а не оценку знаний студента.

Оформление и интерактивность главной: course.css и course.js. Они встраиваются в HTML при сборке. Исходники курса и текущий статус — COURSE_OVERVIEW.md и PROGRESS.md.
