# AI-Assisted Engineering

Русскоязычный курс об инженерной работе с AI: от первого поручения агенту до спецификаций, автоматической проверки и координации нескольких агентов. Основная аудитория — Middle, Senior, Staff и Tech Lead; первый раздел доступен начинающим.

## Как читать

Откройте **[index.html](index.html)** в браузере двойным щелчком. Главная страница содержит все разделы, поиск по темам и фильтр доступных уроков. Для чтения HTML не нужны сервер, Node.js, установка пакетов или платный AI-доступ.

Начать можно с [Р1.01 «Основы работы с AI-агентами»](lessons/01/01-agent-basics/index.html) или [индекса раздела 1](lessons/01/index.html). Из уроков ссылка «Все разделы» возвращает к программе. Markdown-версии находятся рядом с HTML.

Если файлы, терминал и устройство приложения пока незнакомы, рекомендуемый вход: Р1.01 → Р1.04 → Р1.05 → Р1.02 → Р1.03 → Р1.06, далее по порядку. ID и порядок исходного curriculum сохранены.

## Учебное приложение

В разделе 1 доступен [Engineering Workbench — локальный стенд](lessons/01/demo-workbench/README.md): браузерная форма, HTTP API, JSON-хранилище и тесты. Для запуска нужен Node.js; проверенная среда — Windows, PowerShell, Node.js v24.22.1. Внешние пакеты и API-ключ не нужны.

Из корня проекта:

```powershell
node lessons/01/demo-workbench/server.mjs
```

После запуска откройте [http://127.0.0.1:4317](http://127.0.0.1:4317). `Ctrl+C` останавливает сервер. Этот стенд нужен для демонстраций; полный сквозной production-проект ещё не реализован. Условия запуска, ограничения и [фактические результаты проверок](lessons/01/demo-workbench/verification.md) приведены отдельно.

## Сборка и проверка

Для обновления главной навигации после добавления уроков выполните из корня проекта при установленном Node.js:

```powershell
node build-course.mjs
```

Скрипт читает [CURRICULUM.md](CURRICULUM.md) и сохраняет автономный `index.html`, встраивая `course.css` и `course.js`. Порядок и названия тем берутся из curriculum; поясняющие названия разделов заданы в скрипте.

Папка урока имеет вид `lessons/01/01-agent-basics`. Ссылка появляется при наличии `lesson.md` и `index.html`; одни Research / Outline не делают урок доступным. Для отсутствующих материалов навигация выводит **Coming soon**. Сейчас доступны все 68 уроков.

Для пересборки HTML Р1.02–Р1.15 и проверки материалов раздела 1:

```powershell
node lessons/01/build.mjs
node lessons/01/verify.mjs
```

Сборщик раздела 1 сохраняет Р1.01. Проверка контролирует структуру, локальные ссылки, соответствие цитат реестрам, встроенный JavaScript и контрольные суммы эталонного урока. Она не заменяет содержательную рецензию.
