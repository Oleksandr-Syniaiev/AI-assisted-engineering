# Безопасность проекта

Курс публикуется как статический сайт. Локальный Engineering Workbench — учебный стенд для синтетических данных, без production-аутентификации. Его не следует публиковать как серверный сервис.

## Исправления по результатам проверки 03.11.2026

- Локальный preview обслуживает только разрешённые типы публичных файлов. Скрытые пути, каталоги данных, неизвестные расширения и ссылки за пределы корня запрещены.
- Preview и Workbench проверяют Host и Origin; привязка к loopback сохранена.
- JavaScript- и Python-сборщики отклоняют исполняемые URL-схемы, управляющие символы и сетевые ссылки без явно указанного протокола. Разрешены HTTP/HTTPS и ссылки на локальные документы.
- `.env` и локальные варианты исключены из Git; шаблоны `.env.example` разрешены. Ignore не удаляет уже опубликованные секреты и не заменяет проверку.
- На GitHub включены repository-level Secret Protection и Push protection; подтверждение интерфейса не требовало дополнительных лицензий. Настройки применяются отдельно от содержимого Git.
- CI выполняет регрессионные проверки, проверку ссылок раздела 1 и тесты учебного HTTP-приложения. Workflow имеет только право чтения содержимого; checkout закреплён на полном SHA и не сохраняет credentials.

Текст и HTML первого урока не изменены. Исправлены только его служебные сборщик и preview. Реестр контрольных сумм обновлён для этих исправлений; текстовые файлы проверяются с нормализацией CRLF/LF, бинарные — без преобразования. Пути реестра переносимы между Windows и Linux.

## Проверка

Из корня проекта:

```powershell
node --test tests/security.test.mjs
python tests/security_python_test.py
node lessons/01/verify.mjs
node --test lessons/01/demo-workbench/workbench.test.mjs
```

Нужны Node.js, Python 3 и разрешение на localhost для HTTP-тестов приложения. Новые security-тесты вызывают реальные обработчики напрямую, без открытия сетевых портов; временные синтетические файлы удаляются после завершения. Проверка symlink выполняется на Linux CI; на Windows она пропускается, поскольку право создания ссылок не предполагается.

При обнаружении опубликованного секрета сначала отозвать или заменить его у провайдера. Не помещать действующие credentials в публичное issue, пример кода или журнал проверки.
