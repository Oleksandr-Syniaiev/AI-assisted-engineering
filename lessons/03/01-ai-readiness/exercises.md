# Авторская демонстрация — Р3.01

Самостоятельных заданий и сдачи нет. Пошаговый разбор включён в [урок](lesson.md).

Входы: явно описанные синтетические материалы Engineering Workbench. Полного scaffold нет. Платформа: документальный walkthrough; JavaScript-пример Р3.03 требует Node.js 16.9+ из-за Object.hasOwn. Продукты, agents, API и тесты не запускались.

Критерии качества разбора: объяснены вход, механизм, обычный и отказный сценарий; указан owner решения; ожидаемое поведение не названо фактическим; вывод ограничен доступным evidence. Для последующего исполнения нужно закрепить repository snapshot, runtime, tools и permissions.
