# Авторская демонстрация — Р2.05

Самостоятельных заданий и сдачи нет. Полный разбор находится в [уроке](lesson.md).

Вход: синтетический дефект валидации заголовка Engineering Workbench. Среда: описательная модель процесса; для JavaScript нужен современный Node.js. Полного приложения, аккаунта агента и API-доступа демонстрация не предполагает.

Наблюдаемый критерий разбора: читателю показаны входы, границы действий, ожидаемые свойства, способ независимой проверки и условия остановки. Выводы должны соответствовать доступным сведениям, без заявления о непроведённых запусках.

Статус: код и агентный сценарий не исполнялись. Подробности и ограничения приведены в уроке.
