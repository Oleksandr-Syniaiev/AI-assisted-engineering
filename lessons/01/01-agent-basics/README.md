# Р1.01 — Основы работы с AI-агентами

Откройте **index.html** двойным щелчком в обычном браузере. Установка, сервер, интернет и аккаунт для чтения и интерактивной практики не нужны. Внешние источники требуют интернета только при переходе по ссылкам.

## Материалы

- [Читать урок](index.html): оглавление, схема, разбор trace, контракт и раскрываемые ответы.
- [Задания](exercises.html) и [источники](references.html) в том же оформлении.
- Исходные тексты: [lesson.md](lesson.md), [exercises.md](exercises.md), [references.md](references.md).
- [Код и отчёт запуска](practice/verification.md), шаблоны в practice/.
- [Технический self-review](review.md).

Тёмная тема и размер текста переключаются в верхней панели. Кнопка «Печать» использует браузер; перед печатью ответы раскрываются. Поле контракта не отправляется модели или внешнему сервису. Скачайте свой текст перед перезагрузкой страницы.

## Воспроизведение и сборка

Для чтения эти команды не нужны. Для разработчика страницы — установленный Node.js, рабочая папка этого урока:

```shell
node build.mjs
node --test practice/baseline.test.mjs
node --test practice/corrected.test.mjs
```

build.mjs собирает три автономных HTML-файла из Markdown и reader.css/reader.js. Внешних packages нет. Baseline намеренно падает на одном тесте, corrected проходит четыре; это два состояния одного упражнения.

Необязательный временный HTTP-preview:

```shell
node preview.mjs
```

Он печатает локальный URL, слушает только 127.0.0.1 и читает файлы workspace курса. Завершение — Ctrl+C. Для обычного чтения используйте index.html напрямую, чтобы не зависеть от процесса сервера.
