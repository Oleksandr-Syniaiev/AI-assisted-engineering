# Р1.13 — авторская демонстрация

Материал для чтения. Самостоятельных заданий, обязательных файлов и сдачи нет.

## Разбор: Разобранное заполнение для Workbench

Цель — отказ для `"   "`. Входы — `policy.mjs` и соответствующие тесты. Контракт — только строка, `trim()` до проверки непустоты. Инвариант — число отклоняется, валидный заголовок нормализуется. Границы — не трогать UI и хранилище, не устанавливать зависимости. Проверка — локальный тест контракта в документированном каталоге.

Теперь заменим задачу на ошибку сохранения. Хороший шаблон остаётся полезен, но значения полей меняются: входы включают сервер и файл данных, проверка — перезапуск и GET, инвариант — не терять существующие записи. Если в шаблоне осталось «четыре случая title», переносимость не достигнута.

Эта проверка выполнена как редакционный разбор двух сценариев. Модель не запускалась, улучшение скорости не измерялось. Фактические тесты валидатора и стенда находятся в отдельном журнале, а не являются результатом самого шаблона.


## Статус и границы

Локальные исполнения описаны в [журнале](../demo-workbench/verification.md). Запросы агентам — образцы постановки; модельные и внешние сценарии не выполнялись. Вымышленные ситуации и ожидаемый вывод отделены в тексте урока от измеренных результатов.
