# Engineering Workbench — локальный учебный стенд

Один небольшой путь: форма → API → нормализация заголовка → JSON-файл. Поддерживает уроки Р1.03–Р1.15. Это кандидат учебной основы, а не полная реализация сквозного проекта курса.

## Запуск

Платформа примера: Windows, PowerShell, Node.js v24.22.1. Команды из корня курса. Пакеты, установка агента и API-ключ не нужны.

```powershell
node lessons/01/demo-workbench/server.mjs
```

Открыть в браузере `http://127.0.0.1:4317`. Первый терминал занят сервером; `Ctrl+C` останавливает его. В данных допустимы только синтетические заявки. Данные сохраняются в `data/requests.json` рядом с серверным модулем и не нужны в Git.

## Файлы и контракт

- [client.html](client.html): форма и чтение списка; использовать через HTTP-сервер, а не file://.
- [server.mjs](server.mjs): HTTP-маршруты и файловое хранилище.
- [policy.mjs](policy.mjs): только строка, trim, отказ для пустого результата.
- [workbench.test.mjs](workbench.test.mjs): изолированные проверки контракта и HTTP.
- [git-demo.mjs](git-demo.mjs): отдельный временный Git-репозиторий для Р1.07.

API: `GET /health` — жизнь процесса; `GET /api/requests` — список; `POST /api/requests` с JSON `{"title":" Fix CI "}` — создание. Статусы: 201 — создано, 400 — неверный JSON, 413 — тело больше 16 KiB, 415 — неподдерживаемый Content-Type, 422 — неверный заголовок, 500 — внутренний отказ. UUID не является порядковым номером.

## Проверка

```powershell
node --test lessons/01/demo-workbench/workbench.test.mjs
node lessons/01/demo-workbench/git-demo.mjs
```

Нужны разрешения на localhost и временные файлы; для Git-демонстрации нужен Git. Проверки не используют основной data-файл. Удаляются только созданные самим сценарием временные каталоги. [Результаты и версии](verification.md).

## Ограничения

Один локальный процесс и небольшой файл. Синхронная запись блокирует обработку; нет транзакций, crash-safe записи, нескольких writers, авторизации, резервного копирования, идемпотентности POST и production-наблюдаемости. Повреждённый файл не затирается автоматически: API отдаёт 500. `/health` при этом может оставаться успешным. Не открывать стенд в публичную сеть; этот путь использования не предусмотрен.
