## Кандидаты и ограничения повторной сверки

Основные относящиеся к этой теме первичные документы повторно открыты; динамические страницы необходимо снова проверить непосредственно перед drafting. Для SRC-031 (Lost in the Middle) сохраняется ограничение прежней проверки metadata/abstract: полный текст в этой сверке не перечитывался и современные coding agents по нему не оцениваются. Не являются внешними источниками и ещё требуют появления: версия выбранного клиента, scaffold, точный baseline и run logs; они ещё не являются подтверждёнными источниками. Если доступ/условия продукта изменятся, актуализировать соответствующую запись перед drafting.
